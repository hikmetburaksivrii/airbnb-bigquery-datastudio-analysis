**🏠 Project Overview:** Airbnb Is A Global Marketplace That Connects Guests Looking For Accommodation With Hosts Who Want To Rent Out Their Homes Or Rooms Through A Digital Platform. The Platform Manages Listing Publication, Availability Calendar, Pricing, Reservations And Reviews Within A Single System. Airbnb’s Success Depends On Helping Guests Find Suitable Accommodation Options While Enabling Hosts To Generate Consistent Income From Their Listings.

In This Analysis, The Key Question For The Customer Success Team Is: Why Do Some Listings Have Higher Rental Potential Than Others? To Answer This Question, The Relationships Between Listing Price, Review Score, Host Response Time And Calendar Availability Were Examined. The Goal Is To Identify Features Associated With Higher Performance And Provide Hosts With More Effective Recommendations For Pricing, Communication And Guest Experience.

**🔄 Project Workflow:** The Workflow Started With Uploading The Raw Airbnb CSV Files To Google BigQuery. The Data Was Then Explored, Cleaned And Transformed Using SQL Queries, With Each Query Executed Sequentially To Prepare The Required Tables. After Creating The Final Analysis Table, It Was Connected To Google Looker Studio, Where Dynamic Calculations And Interactive Visualizations Were Created To Analyze The Key Relationships Identified In The Project.
